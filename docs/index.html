    选并行方案与 P / D 配比

    均值估算 · 待压测

    按满足 TTFT / TPOT 的单卡输出吞吐排序：输出 tokens/s ÷ P、D 合计 GPU 数。搜索范围内遍历整数配比，不要求用满 GPU；同一配比等比例扩容时模型单卡收益不变，优先展示最小整数配比。1P / 1D 表示一套完整实例，各自包含配置中全部 GPU；模型使用所选 workload 的全部导入点，不受下方曲线勾选影响。

    模型假设与缺失数据校准

    假设均匀分流、稳定泊松到达、独立 P/D 实例，容量可随副本数线性扩展。用每实例请求容量 μ 估算排队 Wq=ρ/[μ(1−ρ)]；这是基于容量的排队近似，未模拟 continuous batching、突发、长短请求混合和链路拥塞。

    TTFT≈完整 Prefill 服务时间 + P 排队 + D 准入排队 + 额外开销 + 一个 TPOT。单步延迟、含排队的 TTFT 均不自动作为服务时间。只支持均值规划，P95/P99 SLO 需要对应压测数据验证。TPOT 也假定输入点代表均值。

    输入/输出长度应与采样 workload 一致；不会将采样外推到新长度。完整输入含缓存命中，非缓存长度只用于非缓存吞吐换算。确认 workload 标签涵盖同一模型、硬件、精度、长度和缓存条件。

    校准值只补充该配置缺失的 prefill_service_ms，适用于该配置全部缺失点；有逐点数据时优先使用点位记录。该值必须覆盖完整输入及所有 chunks、排除等待调度时间；禁用 chunk 也不能自动把单步时间当完整请求时间。

    排队公式与 Little 定律参考（MIT） · 仅借用公式，容量和完整请求延迟分别校准，不能视为推理服务严格的 M/M/1 模型。
